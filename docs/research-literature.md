# 研究ツリー拡張案の出典台帳

確認日: 2026-10-20。対応する候補は[研究ツリー拡張案](research-tree-catalog.md)。

48件の論文・技術資料・開発機関自身の実証報告を整理した。初版45件に輸送関連3件を追補した。
検索だけで見つけた資料を全て数えた一覧ではない。
下記の「確認範囲」に本文該当箇所・著者要旨・公式報告を区別した。全文を一律に通読した網羅的レビューではない。
出版社から取得できなかったものは著者所属機関・NTRSの要旨等へ切り替え、その範囲を明記する。
掲載年・会議年とNTRSの登録ID・取得年が異なるものは、年の意味を併記する。

資料は科学・工学の背景。技術をゲームのノードへ分けること、効果、費用、時間、研究ポイント、
前提関係、外交や人材への影響はゲーム設計上の提案で、論文がゲームバランスを推奨したものではない。
制御環境の生物実験を火星屋外の生育、模型を実際の都市、温暖化モデルを呼吸可能な大気の実証として扱わない。
