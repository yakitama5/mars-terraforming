# 遠景天体の見かけの大きさ

2026-10-26。ユーザーは遠景の惑星のサイズ感へ疑問を示し、実際のサイズ感へ近づけるよう依頼した。
従来の模様や環を読ませる数度の角直径は、今後の基準として維持しない。
今回はこの指示を根拠に見かけの角径を1倍で実装する。任意の拡大案に対する採用回答は得ていない。
主火星の構図・自転・モデル、ゲーム内の全球/近接モデルと進行・保存は変更しない。

## 物理値と座標

| 対象 | 赤道半径 km | 円軌道の半径の基準 AU |
| --- | ---: | ---: |
| 太陽 | 695700（公称光球半径） | 0 |
| 地球 | 6378.1366 | 1.00000261 |
| 火星 | 3396.19 | 1.52371034 |
| 木星 | 71492 | 5.20288700 |
| 土星 | 60268 | 9.53667594 |

- 惑星半径: [JPL Physical Parameters](https://ssd.jpl.nasa.gov/planets/phys_par.html)。
- 軌道の長さ: [JPL Approximate Positions Table 1/J2000](https://ssd.jpl.nasa.gov/planets/approx_pos.html)。
  地球の基準はEarth/Moon barycenterの近似値。
- 1 AU = 149597870.7 km: [JPL Astrodynamic Parameters](https://ssd.jpl.nasa.gov/astro_par.html)。
- 太陽の公称半径: [IAU 2015 B3](https://www.iau.org/common/Uploaded%20files/IAUGA2015-Resolution-B3-recommended-nominal-conversion.pdf)。
- 火星から見た地球が光点である撮影例: [NASA Earth from Mars](https://science.nasa.gov/resource/earth-from-mars/)。

これらはモデルのスケールの基準であり、現在日時の精密な天体暦を再現するものではない。
公転/自転の周期と初期位相、円軌道の簡略化は既存のタイトル演出を保つ。
離心率、光行差、光行時間、屈折、測光の精密計算は導入しない。

`TitleSceneMotion`は共通の太陽中心座標からカメラ座標へ回転した実AUの相対ベクトルを返す。
方向だけへ正規化して距離を失わない。主火星の赤道半径8.06を実3396.19kmへ対応させ、
カメラの火星中心からの高度もAUへ換算して相対ベクトルから引く。

## 角径と描画

観測者から球中心への実距離をd、実半径をrとし、球の接線から角半径θ=asin(r/d)を求める。
カメラからの圧縮描画距離をDとし、描画球の半径をD×sin(θ)とする。
地球の元球半径は3.1、巨惑星と太陽は1なので、各モデルの元半径で割ってroot scaleへ変換する。

位置はcamera + D×観測方向とする。従来の火星中心へ足す方式による数度の偽の視差を除く。
土星の環は球と同じrootで縮小し、元の環/球比2.330901と軸傾斜・扁平率を維持する。
太陽は光球を同じ1倍の基準とし、コロナとBloomの外周を光球の角径へ含めない。
太陽の光球は火星の円軌道基準で角直径約0.35度となる。

惑星の大きさは公転による距離で変わる。元の球を最低pixel数へ拡大せず、
遠景が点状になっても観測角の比率を保つ。モデルの形状/画像の作り直しや品質の削減は行わない。
描画距離を圧縮した太陽の位置から光を求めると各惑星の欠け方まで変わるため、
地球/木星/土星への光は実AUの惑星→太陽ベクトルから別に求める。

## 未分解天体の光点

実角径が1pixel未満の球だけではラスタライズの位置によって消失/ちらつきが生じ得るため、
独立した小さいquadで未分解天体の光学的な点像を加える。球と環自体の大きさは変えない。

- GaussianのFWHMは1 render pixel、supportは±2.5pixel。端の弱い光を惑星の直径とは扱わない。
- pixel footprint内の積分で、中心が動いたときの光量を隣接pixelへ滑らかに配分する。
  10,201通りの画素内位置の数値確認で積分総量の変動は約0.00022%以内だった。
- 実際のScene描画高さ（論理高さ×上限付きpixelRatio）でquadを求める。
  光点は弱い白/青白/黄白色で、露光とLambert位相・距離の簡略減衰を使う。
  視等級や人の眼の感度を校正した測光シミュレーターではない。
- 自身の極小球/環の少し手前へ置き、火星のopaque depthによる遮蔽は維持する。
  PSFだけをHUDへ貼らず、画角外や火星の背後の天体は自然に隠れる。
- quadのgeometryは弱参照で共有、材質は天体/Scene別。追加の画像・依存はない。

GPU上の各球のworld半径とカメラ距離から角径を独立に求め、実AUの値と照合する通し試験を追加した。
