# 円形に切り出した都市の箱庭

更新: 2026-10-15。[前回の接写と質感](city-diorama.md)に続く変更。
今回のユーザー指定は、円形に切り抜いた土地に街と自然が収まる、瓶の中の小世界のような箱庭。
川などの地形が見分けられることを優先する。

## 今回の表現

- 画面外へ続いていた矩形の地面を円形へ切り出し、土と岩の4層の断面を付けた。
- 初期視点と「全域」は、外周と地盤の厚みが収まる構図。「市街」で選択区画へ寄れる。
- 地球は前景を蛇行する川と岸、入り江、奥の丘を組み合わせた。川岸に石・葦・遊歩道、渡河部に板橋を配置。
- 既存の本部と集落は川の南岸へ移し、開発する25区画と川の流れを見渡せるようにした。
- 火星は液体の川を置かず、乾いた谷・氷層・赤褐色の地形で区別する。
- 建設操作中や区画選択中に開発範囲を示す。眺める状態では外周の強い線を抑える。
- 3D初期化中の簡易地図にも円形断面と川を表示し、区画選択を保つ。

透明な瓶の壁や屈折は追加していない。地盤をひとまとまりの小世界として見せる段階。
橋・川・土層・区画外集落は景観であり、新しい建設費、河川ボーナスや水運ルールは導入していない。
区画ID、隣接関係、施設の用途・費用・時間、セーブ形式は維持する。

## 操作

1. 「都市開発」で円形の全景を開く。
2. 施設を選び、地形上の六角を選ぶ。見積もりを確認し、建設を予約する。
3. 「市街」で選んだ土地へ寄る。全景へ戻るには「全域」。
4. ドラッグで移動、ピンチ／ホイール／±で拡大縮小、視点ボタンで回転。
5. 小さい横画面では「地図を広く表示」で情報欄を閉じて全景を眺められる。

## 仮設定と描画の範囲

半径は建設区画の最遠中心から2.0単位の余白（現行25区画で約6.8単位）、底面は-1.35。
川幅は約0.59〜0.85、水位は-0.045。地表は円周192分割・半径方向約0.20間隔、
水面は約0.16格子を川岸と同じ円で切り抜く。水域が円の端に届く部分にも水の断面を設ける。
全域倍率0.70・俯角0.68、市街倍率2.3は仮値。ゲームの期間や地理の実縮尺ではない。

素材とモデルはコードで生成し、追加ダウンロードを必要としない。
地形・橋・植生は静的な共通メッシュを利用し、時間の数値更新だけでは再生成しない。
Flutter 3.47.7 / FlutterScene 0.24.3とlockfile、content district-5、保存形式2を維持。

## 実画面による調整

初回のWeb表示では、海の沈下後に奥の山を足していたため、海側に青い高い崖が現れた。
山を加えてから海底を沈め、海岸・水位・地面の色の境界を一致させた。
水域全体の格子検査で、水面より高い海底が再発しないことも確認する。
また、最前列の六角へ川が近づきすぎないよう河道を南へ迂回させた。

小画面のWeb操作試験ではリサイズ直後の区画選択が一度ずれた。
投影とWidgetの座標、待機後の実ブラウザ操作を切り分け、検証のクリック前に
semanticsの外接矩形が連続して安定することを待つよう変更した。
施設選択、物理座標のタップ、予約取消、セーブ比較という検査内容は維持している。

## 検証結果

- `bash tools/check.sh`：依存方向・整形・静的解析成功、221テスト成功。
- 全5都市で円周と土層底面を72点ずつ、3画面サイズ・2倍率・全周回転で検査。
  全25区画の保持、施設足場の平坦性、川岸の連続性、海底が水面以下であることも確認。
- Chrome WebGL：実操作で5地区を建設し、取消・接写・全域・回転・端区画の再選択、
  小画面844×390の操作、保存再開、別タブ排他、オフライン再読込が成功。
  外部ホスト要求なし、描画エラーなし、検証Nodeは自然終了0。
- iPhone 17 Pro / iOS 26.1 Simulator：実GPUで地表の3地点選択、住宅建設・増強、
  隣接研究、箱庭全景・接写、都市比較、火星居住、保存再開が成功。
  統合試験1分17秒、ドライバ自然終了0。初回シェーダー生成は最大約0.61秒の停止警告あり。
- 独立したコードレビューと2方向の実画面レビューを実施。橋の接続、本部の接地、
  円外への景観物のはみ出しを確認した。
