# 技術で解放する施設・機体・運営方法の案 v0.1

作成: 2026-10-20。Dear Mars の企画精査用。

## 1. 今回の方針

ユーザーは研究ツリー案を肯定し、技術によって都市開発施設やロケット等を解放する仕組みと、
それぞれの解放先のバランスを精査するよう依頼した。**実装はまだ進めないという明示指示。**

研究 → 建設・製造・運営の選択肢が増える → 投資して稼働 → 都市と輸送計画が変わる、という循環にする。
研究完了だけで施設・機体・人口・収益を無償付与しない。

既存96候補すべてに解放先を割り当てたうえで、輸送の不足を補う3候補を追加し、計99候補を比較する。
これは99回の研究購入を確定するものではない。特にE05・E06は一体化を推奨する。
**個々の名前、前提、施設、効果、統合・追加は設計案。ユーザー採用済みの完成仕様ではない。**

以下の解放先・相対的な長所と負担はゲーム設計上の提案。
論文の実測値から施設の採算やゲーム数値を導出したものではない。
科学的な確認範囲は出典台帳を引き継ぎ、追加3件の根拠をS46〜S48に記録する。

## 2. 解放の単位と初期の入口

| 単位 | 研究完了で増えるもの | 実際に使うときの投資 |
| --- | --- | --- |
| 施設 | 都市・現地拠点で建設できる施設の設計 | 用地、建設費、資材、工期、設備搬入 |
| 機体 | ロケット・船・ローバー等の製造候補 | 工場能力、機体費、発射・航路枠、推進剤、整備 |
| 設備 | 既存施設へ追加できる装置・増築 | 改修費、設置能力、電力、必要な担当者 |
| 製法 | 既存設備で選べる生産品・加工方式 | 原料、加工能力、電力、品質確認 |
| 運用 | 航路・共同利用・稼働方法の新しい選択 | 実行費、対象設備、担当者、必要な提携条件 |

すべてを地図上の別施設にしない。温室の栽培方式、炉の変換機、機材の防塵装備等は、
同じ施設の仕様・改修として比較できる。都市の見た目を変える主要施設と、細かな装置を区別する。

研究前提は下表の知見の関係に限り、建設・稼働条件と分ける。
「—」は共通の入口以外の個別研究前提なしという案で、無料・初期完成という意味ではない。
「+」は両方、「または」は代替。通常ノードの直接前提は最大2件の案とする。
先端研究の費用は基盤研究より重くするが、一律に枝を全部購入させる段階制は置かない。

最初から利用できる、または共通の入口で建設できる基盤の案:

- 基礎研究所と最低限の研究者を確保する手段。専門研究棟がなくても共通RPを生産できる。
- 住宅・商業・人材育成・通常の受注工場。研究所の維持と増員へ戻れる収入源を残す。
- 基礎宇宙港と化学式の小型貨物輸送セット。地球打上げ、巡航、小型着陸を含めて最初の探査へ進める。
- 最初の設備に使える通常電源、基本通信、保守、輸入消耗品。高度な電力網等の研究前から稼働できる。

初期所有数・価格は未決定。この入口は現行セーブに無償設備を追加する変更ではない。
最初の貨物輸送に、月面工場・軌道デポ・核熱推進を要求しない。

## 7. 都市の稼ぎ方と研究の稼ぎ方

施設の産出量はまだ設定しない。まず、同じ人員・土地・資金をどこへ使うかという競合を作る。
全施設が資金とRPを同時に最大生産する設計にはしない。

| 施設群 | 通常の主用途 | RPを得る場合の配分案 | バランス上の役割 |
| --- | --- | --- | --- |
| 商業・一般事業 | 都市の収入 | 原則、直接RPは生まない | 研究施設を運営する資金源 |
| 基礎研究所 | 全分野共通の研究 | 研究者・予算を使ってRP | 安価に始められ、最後まで研究を止めない入口 |
| 温室・培養・材料等の専門施設 | 対応する製品の生産 | 設備の一部を実験に回し、製品産出を減らしてRP | 生産都市か研究都市かを選ぶ |
| 資源分析所・現地ラボ | 調査・試験 | 研究者と解析枠を研究へ割当 | 立地情報とRPの両方が必要な方針に向く |
| 宇宙港の試験区・運航棟 | 打上げ・輸送・受注 | 選んだ試験で発射・整備・人員枠を使ってRP | 収益便・自前輸送・試験が競合 |
| 人材育成施設 | 研究者・技術者等の確保 | 研究を同時に行う場合も教員・予算を共用 | 即時RPより将来の人員供給を重視 |
| 共同研究施設 | 提携設備を用いた研究 | 提携・利用枠・費用・研究者がそろってRP | 外交・提携を生かすが、自前研究も継続可能 |

- 共通RPはどの施設で生産しても全分野に投入できる。別色のポイントを追加しない。
- 空施設はRPを生まない。生産部門の担当者と研究者を、同じ時間に二重配置しない。
- 専門施設は特定の設備・立地・目的に合う時に有利にする。無条件に最高のRP/費用を持つ一棟を作らない。
- 研究施設を増やすほど維持費・人員・土地・電力等が必要になり、資金稼ぎと両立する規模を考える。
- RP産出設備の解放は研究の選択肢を増やすが、研究費だけで次々に無償増殖する仕組みにしない。
- 定常研究は施設の稼働でRPを作れる。発見・実績の一度限りの報酬と、通常の研究運転を混同しない。
- 稼働配分を割合・モード・予約枠のどれで操作するか、専門性のボーナスを付けるかは未決定。

## 8. 先に解消したバランス上の問題

| 問題 | この案での扱い |
| --- | --- |
| 研究所を解放するために研究所のRPが必要 | 基礎研究所と人員確保は入口に置き、専門施設を必須にしない |
| 月面工場とシャトルが互いの完成待ち | シャトル・デポは地球から運んだ対応推進剤で先に使える |
| ロケットの前提に全分野の大量研究 | 通常の直接前提を最大2件にし、設備の電源・補給は複数方式で満たす |
| 機体研究だけで燃料まで無償に手に入る | 機体、推進剤製法、製造施設、貯蔵、運航枠を分ける |
| 再使用機が初便から常に最安 | 回収・再整備の固定費と機体占有を設け、輸送頻度で選ぶ |
| 大型機が小型機の完全上位互換 | 少量貨物・低搭載率では小型機を選ぶ理由を残す |
| 全部の技術が同じ「効率上昇」 | 施設・機体・原料・立地・運営方法を中心に解放する |
| 防護・保守・熱制御が細分化され、最初の設備が動かない | 基礎キットに必要機能を含め、各研究は別仕様・規模・改修を解放する |
| 発電所ひとつに炉心・変換・制御・分散の4研究が必須 | E05・E06を統合し、E07・E08は任意の運用・配置改良にする案 |
| 生物採鉱・給電で部品研究を水増し | B17は独立の試験判断が弱ければ統合。E17は固定受電器込み、E18は移動体向け |
| 予測や安全な停止が研究なしではできない | 基本の費用・負担・危険表示、休止、優先配分は通常操作に含める |
| 低圧培養・局所温暖化で火星の屋外居住が完成してしまう | 用途と成立条件を限定し、全球EDの判定は今回決めない |

ここで確認したのは選択肢と条件の構造。研究費、収支、期間、産出量による均衡は未検証。
