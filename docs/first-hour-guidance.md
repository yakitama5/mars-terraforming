# 最初の1時間の案内・Tips・完了通知

更新: 2026-10-15。導入ガイド、状況別Tips、予約の操作、完了通知、画面間の導線を
5つの観点として、親が統合し、3サブエージェントと5巡の改善を実施。
ゲームの費用・工期・解放条件は変更せず、既存の予約と進行エンジンを使う。

## 操作と今回の変更

- 惑星マップの導入カードに6工程の達成数を表示。手引きは生命維持、地球の初地区、都市基盤、
  キット製造、火星への輸送と居住方式、火星居住を扱う。0〜60分は目安で、時間だけでは達成しない。
  順番や期限は強制せず、既存セーブの成果を認識し、1時間を過ぎても未達の手順を確認できる。
- 画面下の「ガイド」は全タブから開ける。主な行動、手引き、Tips、表示設定をまとめ、
  惑星マップでガイドを隠しても再訪できる。
- Tipsは休止・資金・人員・資材・前提研究・無期限反復・居住方式・提携などを判定し、
  優先度が高い1件を表示。対応する設備、研究、製造、輸送、人員配分へ移動できる。
  非表示にした警告は原因が解消されるまで抑制し、別の計画や再発時には再表示する。
  教育用Tipsは非表示を維持し、「非表示にしたTipsを戻す」で復元できる。
- 予約一覧に1回の所要時間と未払い費用を表示。「次に実行」で後続を先頭へ移せる。
  費用確保済みの現在の1回を中断せず、終了後から新しい順番を使う。
  取消・反復終了は対象と影響を確認してから実行する。予約数は最大24件。
- 研究ツリーに残り時間、予約位置、休止・待機理由を表示。予約済み研究の詳細から設備一覧へ移れる。
  全体表示と文字拡大に合わせてノードを配置し、読み上げの重複を避ける。
- 画面下の「通知」で建設・増強・研究・製造・輸送・育成・受注の完了を確認できる。
  通知を選ぶと対象の都市・研究・設備へ移る。未読件数と直近の完了を表示し、通知表示は任意。
  現在はアプリ内通知。OSのプッシュ通知やアプリ終了中の通知配信は追加していない。
- 通知・ガイドの設定保存に失敗するとダイアログ内にも失敗と再保存を表示する。
  保存競合で進行停止した場合も、開いていた手引きを閉じて状態を確認できる。

## 保存と時間

進行形式2・content district-5は維持し、通知と案内設定を省略可能な保存項目として追加した。
旧保存では通知は空、案内表示は有効で始める。過去の終了履歴から通知を作り直さない。

完了通知はゲーム成果と同じ世代へ保存する。単調増加IDと既読位置を持ち、同じ予約の未読反復を
まとめ、最新48件を保持する。既読操作が参照したIDより後の完了は未読に残す。
通知の閲覧や既読化は報酬を付与しない。通知は記録であり、予約や報酬の実行元ではない。

Tips非表示IDは現在の警告と教育用のIDだけを残し、終了計画や解消済みの警告を取り除く。
教育用IDだけの場合は、長期不在の完了境界ごとにTips全候補を再計算しない。

## 5巡の記録

| 巡 | 確認と改善 |
| --- | --- |
| 1 | 6工程の手引き、状況別Tips、予約の費用・期間、完了記録、全画面の入口を実装 |
| 2 | 通常待機と停止を分離、取消確認、ゼロ人員・再発Tips、再起動と時計後退で通知の重複を検査 |
| 3 | 資源不足からの直接誘導、研究全体表示・文字1.4倍対応、一括製造・輸送や旧工程からの達成を認識 |
| 4 | 3通りの序盤ルート、1年の一括/分割保存再開、既読と同時の完了、保存失敗と二重ダイアログをレビュー |
| 5 | 読み上げ・育成分類・非表示判定負荷を修正、小さい横画面・Web・iOSと統合回帰を確認 |

序盤3方針のシミュレーションでは35分で火星居住24人、60分時点で6/6達成。
60分の残金は4,522 / 3,436 / 3,688ドル。公開コマンドから進めたルートの測定であり、
全員の到達保証や実時間のプレイテストではない。
