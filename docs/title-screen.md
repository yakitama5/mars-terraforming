# 火星と宇宙のタイトル画面

2026-10-25。今回のユーザー依頼により、毎回の起動でOPより前にタイトル画面を表示する。
上にDear Mars、下に大きな火星を置くFigmaの絵コンテを基準とした。
参照: [絵コンテ](https://www.figma.com/design/0vWrMkGgHBny1U76P0b2J2/Untitled?node-id=1-2)。
Figma接続アカウントでは権限エラーがあったが、ブラウザから共有絵コンテを目視確認できた。
Figmaの原稿は変更していない。

## 起動と操作

- 保存の読み込みと初回保存が成功した後に表示し、破損・未知形式・別タブの停止を迂回しない。
- 画面全体のタップ/クリック、Enter/Spaceで開始。短い暗転中は重複入力を防ぐ。
- 新規世界はタイトル→既存の3D序章/会話/命名→ゲーム。既存世界はタイトル→ゲーム。
- タイトルを見たという値は保存しない。コールド起動のたびに表示し、背景復帰だけでは戻さない。
- 新規世界の導入前の資金保護は既存Controllerを使用。既存世界は従来どおり放置進行・自動保存する。
- 描画の準備に失敗しても開始操作を残す。動きを減らす設定では宇宙を静止する。

## 3D表現

背景、星、太陽、地球、火星、探査ロケット、衛星、小惑星はFlutterSceneの3D形状。
静止画やFigmaのスクリーンショットを背景として使用しない。ゲームと同じ固定版
Flutter 3.47.7 / Dart 3.13.5 / FlutterScene 0.24.3を維持する。

火星は連続した地形メッシュで峡谷、盾状火山、クレーターの床と縁、極冠と地層を造形。
表面はマットな少数の色面を基本に、輪郭の大気光と照明で奥行きを付ける。
見える緯度の頂点を増やした約10万三角形と、1024×512の砂塵の色/法線マップを使用。
テクスチャはモデル内で一度だけ生成し、ミップ込み約5.33MiB。再描画のたびには生成しない。
形状・配色・位置は独自に作った模式表現であり、実測地形や天体配置ではない。
ロケットのノズル/フィン/断熱部、衛星の通信皿/断熱材/太陽電池セル、
入植地のドーム骨組み/窓/設備/太陽電池は局所モデルとして組み立てる。

火星とカメラは固定。星空の緩い回転、地球の自転、衛星の周回、雲の流れを継続し、
探査船と小惑星は間隔を空けて横切る。演出時刻は単調Tickerで、ゲームの時計・乱数・保存とは分離。
休止・非表示中はTickerを止め、復帰時の巨大な時間差を演出へ適用しない。
毎フレーム形状を再生成せず、最大30fps/描画倍率1.5で位置と姿勢だけ更新する。

## セーブ進捗の反映と境界

`presentation/title_scene_data.dart`がGameStateを読み取り、
`rendering/title_scene_snapshot.dart`の値へ写像する。描画からdomainへの依存は追加しない。
完成した火星の地区/施設と居住人口に応じ、拠点、無人設備、灯り、限定的な緑や薄雲を重ねる。
研究の解放だけ、地球/月の施設、建設予約中のものを完成した火星へ反映しない。
旧形式の居住と地区の二重計上を避け、休止施設の実体は残す。

現行ゲームには全球の気温・気圧・大気の保存値がない。
色・大気光・薄雲は居住/温室/現地の水・ガス設備を根拠にした**タイトル限定の未来の印象**。
全球の環境計算や呼吸可能判定、新報酬、全球ED、復元、周回のルールは追加しない。
これらの環境値が正式実装された場合は同じsnapshotへ接続する。
保存形式、content版、費用、期間、既存の解放条件を変更しない。

### 実表示の確認

- 最終版の静的解析とタイトル関連29テストが成功。地形の継目・極・法線・面向き、
  局所的な峡谷、砂塵の再現性、小画面/文字拡大、連打/キーボード、初回保存ガードを確認した。
- Web releaseが成功。独立Chromeで `tools/title_smoke.cjs` が自然終了0。
  1440×810/568×320、3Dの動き、初回の資金保護、クリック→OP入口、
  既存世界fixtureの再起動とEnter/Space、オフライン再開、同じworldId、外部取得なしを確認した。
  既存の `completeFirstRun` を使った初回の試験は、現在の「技術を解放する」に対して
  旧ラベル「研究を予約する」を待つ補助処理で止まった。タイトル用ハーネスでは新規OP入口と
  既存世界を分けて確認し、全ゲームのWebチュートリアル完走成功とは扱わない。
- iPhone 17 Pro Max / iOS 26.1 Simulatorの `integration_test/title_screen_test.dart` が成功。
  新規/発展後、約18秒の待機、固定カメラ/火星と動く恒星/衛星/地球、OP前の順序、
  既存継続・背景復帰・再起動、完了済み受注の二重付与なしとGameEngine一致を確認した。
  通常/開発のユーザーセーブには触れず、一時保存だけを使用した。
- GPU描画と実スクリーンショットを比較して3巡調整。横一線の溝、地球の大気縁の自転、
  裏面しか見えない衛星の翼を修正し、北半球の峡谷・入植地・雲を読める位置へ整えた。
