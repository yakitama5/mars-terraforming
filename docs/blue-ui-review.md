# 青を基調とするUI・土地効果のレビュー

更新: 2026-10-16。今回のユーザー指定を受け、地球の青を基調に、文字量と配置判断を見直した。
円形の箱庭を主役にする方針、地区の費用・期間・収支・隣接ルールは維持する。

## 第1巡: 重要な判断が伝わるか

発見した問題:

- 選択・利点・警告に同じミント色と銅色を使っており、色の役割が曖昧だった。
- 「立地・隣接ボーナス」に地形名と隣接施設名だけを並べていた。工業隣接による住宅の減収も、詳細では「＋」付きで見えた。
- 完成後の純収支が負でも利点と同じ色だった。施設候補に用途・基準額・長い操作説明が重なり、狭い横画面では主要操作まで読む量が多かった。

実装:

- 操作と選択は青、利点はシアン、注意は琥珀、損失はコーラル。符号・加減アイコン・「赤字」「高い／安い」などの文言を併用する。
- 資金・収支・主操作を維持し、都市の予約ボタンを短文化。アクセシビリティ名と既存の自動操作の入口を保つ。
- 施設候補の説明を短縮し、基準費用と用途は維持。選択状態はチェック、未解放は鍵でも示す。
- 土地・隣接の効果を税収や効率の増減として表示。詳細を開くと隣接区画番号・施設名・休止状態を確認できる。
- プレイヤーが名付けた都市名を都市セレクター、地図、比較候補に反映する。

## 第2巡: 説明の正しさと小さい画面

追加で見つけた問題と修正:

- 太陽光地区の高台効果は隣接施設へ届くため、単独地区だけの値では説明できない。既存の進行計算をそのまま使い、配置前後の全体差分から土地と隣接の寄与を求める。
- 工業が既存住宅の税収を下限0まで下げる場合、失う海岸収入を地形の欠点と誤説明しないよう、税収下限による変化を隣接へ割り当てた。土地・隣接の説明値は表示用で、ライブ進行の式は変更しない。
- 効率上限に達していると、潜在的な土地効果と実際の効率増分が異なる。上限到達を明示し、上の完成後効果が実際の増分、内訳は上限前と説明する。
- 設備休止時に効果0だけを見せると地形に効果がないと誤認するため、「設備休止中・再開すると効果が有効」を表示する。
- 詳細の長文は任意開閉。固定予約ボタンと地図の幅を保つ。既存の568×320/文字1.4倍の画面試験を維持する。
- 統合試験で開閉式説明のListTileが都市パネルのColoredBoxより後ろへインク描画するassertを検出。説明自身に透過Materialを設け、着色パネル内で開閉する回帰条件を追加した。

## 検証と制約

- 新規回帰試験: 土地効果、双方の工業隣接減収、高台発電、増強の追加分、設備休止、効率上限、税収下限、表示の符号・アイコン・色、隣接区画説明、赤字HUD。
- 六つの文字色について、三つの青背景に対するコントラストを独立計算。最小は6.22:1で、4.5:1以上。これは色覚当事者による試遊結果ではない。
- GPU・Flutterビルドを使わないDart実行で、初期赤字、海岸税収、工業隣接減収、高台発電の土地/隣接寄与、税収下限と増強時の残り1ドルの減収を確認した（8項目成功）。
- 担当Dartの整形を実施。Flutterの解析・テスト・Web/iOS検証は共有checkoutの競合を避け、親の統合検証で直列実行する。担当から成功済みとは扱わない。
- 以前の実スクリーンショットで問題点を確認。追加の844×390のOP/命名実画像では、短い説明・主操作が画面内に収まることを確認。Web実操作、iOS Simulatorの結果は [統合記録](blue-horizon-improvements.md) を参照する。
- 新しい収支、隣接ルール、河川ボーナス、地形ボーナスは追加していない。河川と橋は引き続き景観。

今後は実プレイヤーの試遊で、地図・効果表示・主操作の視線移動と色覚の違いによる読み取りを確認する。
