# 都市投資と序盤のペース

2026-10-13 / content `district-3`。この記録は `district-2` の調整値を更新する。

## 確認済みの方向と実装範囲

- 1ルートの能動的な操作・計画は**累計約20時間**を目標にする。以前の50時間案を更新。
- オフライン待機はこの20時間に含めない。初回EDまで**現実4〜6週間**の目標は維持する。
- 最初の建設は約5分。最初の1時間は配置・受注・研究・輸送を並行して遊び、徐々に長い予約を任せる設計にする。
- メニュー・設定・オープニング・チュートリアルは後回し。今回はゲームの投資判断を改善する。
- 全球環境とEDは未実装。加速した試走の日数や操作数を、実際に20時間楽しめる証明として扱わない。

企画書第4章の「1日1〜2回・各数分」は古い調整仮定。今回の能動プレイ目標を優先する。
20時間を28〜42日へ均等に割れば1日約29〜43分だが、毎日その時間の操作を要求する仕様ではない。
最初は連続した1時間、その後は短い確認と、都市や輸送網を組み替える長めの計画を組み合わせる。

## 実装した投資の違い（すべて仮値）

| 投資 | 費用 | 基礎工期 | 土地 |
| --- | --- | --- | --- |
| 新設 Lv.1 | 基本費用 ×（100 + 同都市の完成区画数×12）% | 同じ整備率を適用 | 1区画追加 |
| Lv.1 → 2 | 基本費用の175% | Lv.1の80% | 追加なし |
| Lv.2 → 3 | 基本費用の250% | Lv.1の120% | 追加なし |

新都市の最初の区画だけ、高原科学都市は1,200 Cr・15分、エリシウムは1,600 Cr・45分、
ヘラスは2,400 Cr・90分を加算する。最初の地球都市とアルカディアには加算しない。
工期の合計を建設設備の効率で短縮する。費用の端数は切り上げ。

増強は隣接を育てた区画と土地を活かし、共用工場の占有時間を抑える。
新区画は小さい投資で能力を増やせるが、密集都市では整備費が増す。
新都市は最初の開拓負担があり、複数地区まで育てれば安く展開できる。
隣接効果の式と研究段階による効率上限30/45/60%は維持した。上限到達後は実際の追加効果が0になる場合も見せる。

見積もりは**着工時点の完成区画・効率**で確定する。予約順や先行工事で未着手の金額・工期は変わる。
すでに着工・支払い済みの作業は再請求せず、従来の残り時間を維持する。
新都市の複数予約は同じ建設設備で順に処理するため、初回開拓費を二重に払わない。

## 序盤から放置への移行（現在値）

| 工程 | 基礎工期 | 費用 |
| --- | --- | --- |
| 住宅 / 発電 | 各5分 | 350 / 650 Cr |
| 都市基盤研究 | 8分 | 700 Cr |
| 研究 / 工業地区 | 10 / 12分 | 1,200 / 1,500 Cr |
| 初期火星居住地区 | 10分 | 700 Cr + 到着キット1基 |
| 再使用輸送研究 | 30分 | 6,000 Cr |
| 自動化生産研究 | 90分 | 20,000 Cr |
| 閉鎖循環 / 軌道補給研究 | 3 / 4時間 | 40,000 / 120,000 Cr |
| 現地資源 / 都市連携 / 広域産業 / 地域居住網 | 12 / 24 / 24 / 48時間 | 600,000 / 1,200,000 / 900,000 / 1,800,000 Cr |

住宅で税収を育て、受注を建設やキット製造へ差し替える。その間に研究所や宇宙港も使い、
初居住後は工業の実証・次の研究を予約して離席できる。期間だけでなく、費用・実証条件でも進行が決まる。
短い作業を毎回手動で繰り返すことは強制せず、有限/無期限反復・分岐待ちの既存ルールを維持する。

## 操作と発展の見せ方

1. 都市開発で候補を選び「比較に保存」。完成区画を選べば増強候補を保存できる。
2. 別の区画・都市を選んで「候補を比較」。本体・都市整備・初回開拓の費用と工期、純収支、土地、実際の効率差を並べる。
3. 閉じて配置を予約し、「設備・進行」で受注との順番を決める。

比較は予約や時間を進めない。候補は画面をまたいで保持する一時メモで、アプリ再起動後の保存はしない。
見積もりは最新状態から再計算し、予約済み・条件不足・保存後の完成を区別する。最大Lvの架空の増強は保存できない。

都市の完成区画と総Lvを表示し、候補地→拠点（総Lv1）→成長都市（8）→中核都市（20）を目印にする。
これは見た目と達成感の目印で、追加報酬や倍率ではない。球体上の建物・ドームも従来どおり総Lvに応じて増える。

## 改善ループと残る検証

- 旧増強の費用・工期4倍/12倍では新設に比べた利点が弱かったため、費用と設備占有時間を別の倍率にした。
- 単発だけの比較では新都市の開拓負担が目立つため、3地区以上の投資も比較するハーネスを追加した。
- 序盤の数時間研究を8分からに変更。初回60分の公開経路で、完成・資金・判断可能な時点を記録する。
- 独立レビューで最大Lvから存在しないLv4を比較できた表示を見つけ、保存・比較と架空の見積もりを止めた。

### 比較試走の結果

同じ6区画の都市で、海岸住宅の増強は613 Cr・3.77分・純収入+17、海岸新区画は602 Cr・8.11分・+14。
単純な安値か、短時間で既存の隣接を伸ばすかが異なる。高原研究地区1か所は既存都市2,064 Cr・16.23分に対し、
新都市2,400 Cr・23.58分。しかし3地区まとめると既存6,624 Cr・52.08分、新都市5,232 Cr・45.85分となる。
18区画の密集都市では3地区11,808 Cr・研究効率+22%・純収支±0、新都市5,232 Cr・+18%・純収支−12。
新都市の安さに対し、集積した都市には隣接による利点が残る。これらは比較用状態での例で、全配置の最適性は保証しない。

初期900 Crからの60分経路は2通り試した。研究地区を先にする経路は初輸送34.71分、初居住44.71分。
キットを先行して工場・宇宙港・火星を並行利用する経路は初輸送21分、初居住35分。
代わりに研究地区の完成は26.4分から29分へ遅くなる。初居住までの最大判断間隔は14.4分から8分に短縮した。
改善経路の60分時点は6地区、24人、3,037 Cr、10の判断時点、未完了の研究予約が残る。
後半の工業建設・資金待ちには最大21.46分の空白があり、**1時間すべてを能動的に遊べると実証したわけではない**。
比較・先行予約を考える時間も含めた実際の手触りは、次の試遊で継続して評価する。

全10研究と火星2都市への公開操作経路は223.427時間（約9.31日）、48人、キット3、1,275,251 Crで到達。
これは現在の試作範囲の経過時間で、全球EDや最適経路の所要時間ではない。
時間の一括/分割、時計前後退、資金/資材/分岐待ち、反復終了、保存回復、旧支払保持を含め、
`bash tools/check.sh`は依存方向・整形・解析と**127テスト**を通過した。

Web releaseとChromeの実操作で都市の発展、候補保存、都市をまたぐ比較、844×390のスクロールと閉じる操作、
オフライン再読込、複数タブのロックを確認した。検証用Nodeは手動終了なしで終了コード0。
実画面を見て、小さい横画面では費用内訳より総額・占有時間・土地・効果を先に表示するよう再調整した。
