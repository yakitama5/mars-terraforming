# 3Dの未来序章とノベル形式の案内

更新: 2026-10-16。今回のユーザー指示で、OPは3Dモデルをレンダリングする映像演出へ変更する。
採用済みのミナの絵をそのまま大きく左下に表示し、半透明の吹き出しで説明する。
スマホは横向き固定を維持する。過去の静止キーアート中心のOPを、今回の方針で更新した。

## 導入の流れ

1. 40秒の未来序章。都市開発→ロケット打ち上げ→月面基地→火星探査→火星移住を各8秒で描く。
2. ミナとの3幕の会話。街の収入→研究→製造→輸送、最初の閉鎖居住、ドームと地下の選択を伝える。
3. 地球・火星の最初の街とロケットを命名し、開発を始める。
4. 導入手引きは現在の工程を会話で表示。「6工程」から全体像・過去の説明へ移れる。
   Tipsの「詳しく」と、居住編EDにも同じ会話表示を使う。通常HUDは地図を操作できる大きさを保つ。

40秒・各8秒・字幕とカメラは今回の演出値であり、ユーザー確定の最終尺ではない。
月面基地を含むOPは目指す未来の描写で、現在のゲームで月面基地を開発できるという仕様追加ではない。
全球判定・復元・継承・収益化・既存の進行数値は変更しない。

## 実装

- `lib/rendering/opening_cinematic_*`: 実際の地表、建物、クレーン、ロケット、基地、探査車、ドーム、温室、人物。
  透視投影と移動カメラ、照明、影、空、透明外殻を使う。映像ファイルの再生や平面絵の拡縮ではない。
  形状を初期化時に作り、親から渡す0〜1の再生位置で姿勢を決める。内部時計・保存処理はない。
- `MissionCinematic`: 再生時計、5場面字幕、暗転、一時停止、「物語へ」、背景復帰を担当。
  3Dの準備後に再生開始。初期化失敗時も「物語へ」で先へ進める。
  動きを減らす設定では各場面の静止画を「次の場面」で手動送りする。
- `MissionDialogue`: 左下の大きなミナ、青い半透明パネルと吹き出しのしっぽ、話者名、見出し、文字送り。
  タップは全文表示だけで、次の台詞へは進まない。「次へ」などの操作は本文スクロールの外に固定する。
  字幕の切替は短いフェードと移動。ミナの表情・うなずき・通常時の瞬きは共通部品を再利用する。
- 読み上げは全文を一度に提示。動きを減らす設定では即全文・静止。
  アプリ非表示・別画面に覆われたときは動作を止める。
- iOS/Androidの横画面指定とWeb PWAのlandscape設定は既存を維持。
  ブラウザ縦画面には閉じられる回転案内を表示し、保存状態や現在の会話を作り直さない。

新規世界はOP・会話・命名を終えるまで既存の資金凍結を維持する。
既存セーブにはOPを自動挿入しない。ガイドからの再視聴は通常進行を止めず、名前・報酬を変更しない。

## 残る調整

- 今回は手続き的に組み立てた3Dモデルの演出。商用の専用キャラクターリグ、ナレーション、音楽、効果音はまだない。
- iOS実機とAndroidのフレームレート・電池・長時間GPUメモリ、Safari/Firefoxは未検証。
- 尺、カメラ、字幕、音の方向は実映像を見て次の評価を受ける。月面開発や全球居住のルールは別の判断事項。
