# 地球・月・火星の段階開発

2026-10-21。今回のユーザー依頼により、新規世界は地球だけを表示し、初打ち上げ後に月、
月面開発後に火星を解放する。以前の「地球から火星への直送を最初の経路とする」試作、
「月は直接輸送と並ぶ任意の経路」という企画上の案を更新する。

## 進め方

1. 地球の共用宇宙港で衛星打上げ受注を完了すると、月を選べる。
2. 生命維持研究と工場の居住キット製造を使い、月へキットを輸送する。
3. 南極月面拠点の25区画に月面基地を建設し、月面打ち上げ基地を建設する。
   各建設で月のキット1基を使う。最初の2施設を建てるために月資源の上位研究は必要としない。
4. 月面打ち上げ基地から火星探査機を送り、完成後に火星を選べる。
5. 火星へ居住キットを輸送すると、従来の初輸送実績と都市開発・居住方式選択へ進める。

月面の発電地区・資源採取地区も配置できる。月は灰色の球体と乾いた箱庭として描画し、
地球の河川や火星の赤い地面を流用した表示にはしない。
惑星マップと都市の選択欄は未解放の天体を隠す。輸送画面には現在進められる段階と条件を表示する。

## 設備への投資と費用

下記はゲーム用の仮値で、実際の建設費・航行時間・実現予測を表さない。
数値は `lib/domain/game_content.dart` に集約する。

| 計画・施設 | 基準費用 | 基準時間 | 内容 |
| --- | ---: | ---: | --- |
| 月へのキット輸送 | 140ドル | 150秒 | 地球キット1基を月へ移す |
| 月面基地 | 450ドル | 180秒 | 月面開発の入口、生命維持研究と月キット1基 |
| 月面打ち上げ基地 | 900ドル | 300秒 | 月面基地が必要、月キット1基 |
| 月面発電地区 | 350ドル | 180秒 | 月面補給を支援、月キット1基 |
| 月面資源採取地区 | 1,200ドル | 600秒 | 現地資源研究、氷・鉱床、月キット1基 |
| 火星探査機の打ち上げ | 180ドル | 240秒 | 月面基地と打ち上げ基地が必要、一度だけ |
| 宇宙エレベーター | 240,000ドル | 24時間 | 地球の任意大型地区、Lv.1のみ、維持24ドル/分 |

エレベーターは軌道組立と複合遮蔽材料の研究を前提とする未来設備。
既存98件の研究ツリーに対して新しい必須の研究購入は増やさず、既存研究の応用先を追加する。
エレベーター完成で火星へ自動到達したり、研究だけで設備が無償付与されたりはしない。

打ち上げ費用は稼働中の月面基地＋打ち上げ基地で15%、さらに月面発電＋採取で10%、
地球の宇宙エレベーターで35%削減する。合計上限60%。同種を複数建てても割引率は重複しない。
割引対象はゲーム内で打ち上げ費用を持つタスクだけとし、建設・研究設備導入へは適用しない。
各回の着手時に再見積もりして支払い、端数はドル単位で切り上げる。
稼働停止で割引も止まるが、すでに費用を払った現在の1回は再徴収・返金・工期変更をしない。
月面建設班の基本維持費は0とし、追加地区の維持費で月面運営の負担を表す。

これは本作で選んだ段階進行と未来技術の設定であり、現実の火星探査に月面基地が必須という主張ではない。
既存月技術の「地上実証」は保存互換性のため保持し、新しい月面地区とは区別する。

## 保存と既存世界

保存はschema 2 / content district-9。月キットと旧世界の天体アクセス権を同じ保存世代へ記録する。
district-8以前も読み込み、既存の資金・研究・既知研究・専門職・提携・地区・支払済み工程を保持する。
旧世界の火星貨物・実績・住民・地区・火星向け予約等に進行がある場合は、月と火星へのアクセスを維持する。
月面設備や報酬を遡及で無償付与せず、地球だけの旧世界は段階進行へ移る。
旧研究の可視範囲を保つ移行と、新規世界の子へ深まる発見順を区別する。
