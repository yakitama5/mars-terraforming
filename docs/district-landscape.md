# 六角地形から広がる街区と施設配置

後続の質感・接写の変更は [箱庭景観](city-diorama.md) を参照。以下は前段の実装記録。

更新: 2026-10-14。ユーザー提供のCivilization VI画像と前版の実画面を比較し、
六角上に小さな模型を置く印象から、土地そのものに住宅街・研究施設群が広がる表現へ改善する。
参考画像のアセットは使用せず、本作のコードで生成した簡単な3D形状を使う。

## 今回の比較と実装

| 参考画像で重視した点 | 前版の課題 | 今回の改善 |
| --- | --- | --- |
| 土地の上に広がる地区 | 小さな単体施設と台座が目立つ | 台座を外し、六角内へ複数棟・街路・設備を配置 |
| 草地・海岸・山地の違い | 地形が白っぽく、区画線が強い | 頂点色のsRGB→linear変換を修正、草地・岩・砂・浅瀬をつなぐ |
| 地図を見ながらの建設判断 | 詳細パネルが長く、何をどこへ建てるか分かりにくい | 施設選択→地表の候補比較→予約。費用・期間・隣接を短く表示 |
| 都市が成長する外観 | 施設ごとに孤立した模型 | 隣接完成地区間に道路、用途別の群構成、増強で密度を増やす |

## 操作

1. 「都市開発」で住宅・研究・工業・発電などを選ぶ。
2. 明るい候補の六角タイルを直接選ぶ。施設・土地の選択だけでは予約されない。
3. 右側で実際の費用・工期・隣接効果を見て「この区画に建設を予約」。
4. 「施設を変更」で用途を選び直し、「配置をやめる」で取消。空地を先に選んでもよい。
5. 完成地区を選ぶと増強、予約区画を選ぶと進行・停止理由を優先表示する。
6. 固定欄の「詳細」（費用・効果と投資比較）で長い内訳を開く。「比較に保存」後は地図へ戻り、
   別の地区や都市から「候補を比較」する。

完成地区の強化ができない場合は、確定ボタンの直上に理由を表示する。
同じ惑星の都市切替では選んだ施設を維持し、配置先は未選択へ戻す。
未解禁の都市では必要研究へ直接移れる。資金不足の予約は既存ルールどおり着工待ちとなり、
後続受注も待つ可能性を表示する。予約順は設備画面で調整する。

地図はドラッグで移動、ピンチ／ホイール／±で拡大縮小。
「都市全体を表示」で全域へ戻り、「地図を広く表示」でパネルを閉じる。
外周は既存25区画の**開発範囲**であり、国境・領土争いのルールを追加したものではない。

## 表現と責務

- 住宅はLv.1から8棟、Lv.2で11棟、Lv.3で14棟に広がる仮表現。
  棟数は見た目であり、人口・税収の新しい計算には使わない。
- 研究は研究棟・実験ドーム・アンテナ、工業は倉庫・煙突・配管、
  発電はパネル群、火星居住は連結ドームなど、用途の輪郭を変える。
- 建物は各位置の地形高さへ接地。自然物は未着工の予約中も残り、着工時に除く。
  増強中は既存施設を残す。予約旗・工事現場・完成は別の状態として描く。
- 多数の建物・街路・自然物は共通メッシュへまとめる。地形と施設の更新契機を分離し、
  秒ごとの進捗表示ではメッシュを作り直さない。
- 地形座標・投影・クリック判定・施設位置を共有し、5都市×25区画のID・隣接を維持。
- Flutter / FlutterSceneの採用版とlockfile、content district-5、保存形式2を継続。
  費用・工期・収支・進行・報酬・研究のルールは変更しない。

## 検証記録

- `bash tools/check.sh`: 依存方向・整形・静的解析に問題なし、202件成功。
  施設先行／区画先行、明示確定前の状態不変、都市切替、前提研究への移動、
  地形の連続性・接地面・線形頂点色・開発範囲の共有辺を確認。
- 独立レビューで保存競合によりengineが停止した後の参照を検出。
  建設確定後・詳細表示中・比較表示中の3経路を修正し、
  停止理由と閉じる操作を残し、保存済みデータを置き換えない回帰試験を追加。
- Chromeの実WebGLで `tools/web_smoke.cjs` 成功。施設選択→候補比較→取消では予約も施設も増えない。
  住宅・研究・発電・工業・住宅の5地区を実操作で建設し、各タイルの保存上の用途とLvを確認。
  小さい横画面844×390でも確定と詳細を操作可能。PCは1440×1000。
- 同じWeb検証で火星居住、研究・設備順序・投資比較・提携・人員、別タブ排他、
  オフライン完全再読込、報酬の継続も成功。外部ホストへの要求なし。Nodeは自然終了コード0。

## 仮仕様と残る課題

地形は実測地図ではなく本作用の架空地域。密度、色、俯角、パネル幅は試遊で調整する。
iOS実機・Androidの描画性能、指の遮蔽と視認性は引き続き確認対象。
特に小画面での近景の見やすさ、接地影、屋根や設備の識別性を次の試遊で詰める。
メニュー、オープニング、全球環境、ED、周回は今回の対象外。
1ルート累計約20時間、初回4〜6週間、最初の1時間に判断をつなぐ方針は維持するが、
今回の表示改善でそのプレイ時間を達成したと判定しない。
