# 物語・命名・最初の1時間の導入

更新: 2026-10-16。今回のユーザー依頼に合わせ、従来の「独立したオープニングは後段」を更新する。

## 体験の構成

新規世界では、同梱画像に緩やかなズームをかける3幕のオープニングを表示する。
字幕は自動で送らず、読み終えたプレイヤーが「次へ」を押す。端末のアニメーション削減設定ではズームを止める。
ネット接続・動画配信・音声は不要。動画ファイルや生成音声を導入済みとは扱わない。

物語の仮案は「地球を育て、その技術を火星の暮らしへ届ける」。プレイヤーの役割、
街の収入→研究→工場で製造→輸送→火星で暮らす、という循環を3幕で説明する。
最初の目標は閉鎖居住区、その先の長期目標は屋外でも暮らせる火星。
秘書は仮称「ミナ」、冒頭の計画呼称「BLUE HORIZON」も最終タイトルの決定ではない。

オープニングの後で地球の最初の都市・輸送ロケット・火星の最初の都市を命名できる。
物語のスキップ後にも命名を提示し、「名前は後で決める」で既定名のまま開発へ進める。
「開発ガイド・Tips」から、全都市とロケットの名前の再編集、物語の再視聴、居住編EDの記録へ移れる。

通常ガイドは短い次の一手と操作ボタンを維持し、ミナの顔を添える。
6工程の手引きでは各工程を一つずつ展開し、物語1文と操作の理由を読む。
研究・都市・製造・輸送・居住の達成判定は実際の進行に基づき、1時間経過だけで完了にしない。
各工程の時間帯は目安。順番・期限・強制待機を追加せず、旧進行もそのまま案内する。

## 状態と保存

- 都市・ロケットの表示名は `MissionIdentity` に分離し、都市ID・予約ID・研究ID・報酬キーを変えない。
- `GameState.cityName(id)` / `rocketName` を表示で利用する。名前は前後空白を除き1〜24文字、改行・制御文字を拒否する。
- `missionIdentity` / `openingSeen` / `openingStarted` は保存の省略可能な項目。旧保存の `openingSeen` 欠落は既読とし、進行中の世界へOPを割り込ませない。
- 新規OPを表示したときだけ `openingStarted` を保存。未完了の間は操作層で時計基準を更新し、読書・命名・再起動で初期資金を消費しない。
- 命名またはスキップの保存成功時点から通常進行へ戻る。保存失敗では導入を完了扱いにせず再試行できる。OPの再視聴中は通常進行を維持する。
- 導入で資金・実績・研究・報酬を付与しない。閉鎖居住と全球居住の判定を混同しない。

## 検証と残る確認

専用の保存・時計テストとWidgetテストを追加。既存画面テストでは `showIntroduction: false` を明示し、
これまでの画面シナリオと新しい初回導入の検証を分けた。

追加したケース: 旧4世代の移行、名称と固定IDの分離、名前変更中の予約保持、無効名拒否、
保存失敗からの再試行、改名後の一括/分割進行一致、3時間の読書、時計前後退、
OP中断後の再起動、スキップ直後の重複進行防止、通常進行の再開、OP再視聴の無変更、
568×320/844×390・文字拡大での導入/命名操作。
追加レビューで、568×320・文字1.5倍・キーボード相当の下170px縮小時に入力欄が潰れる条件を確認し、
見出し・説明・保存エラーを入力と同じスクロールへ移した。操作ボタンだけを固定し、
残り高さが小さいときは余白を縮小する。初回の入力・保存と再編集の入力・キャンセルを確認する回帰テストを追加。

担当内では整形とコードレビューを実施。Flutterの解析・test/build/driveは同checkoutで並列にせず、
親担当が統合検証する。最終結果は共通の開発記録を参照。

実時間1時間の継続試遊、iOS実機の日本語入力とキーボード表示、VoiceOver、長期バランスは未実施。
生成画像の演出は最初の試作であり、ナレーション・音楽・本格的な動画制作は未実装。
物語の固有名詞・台詞・1時間の判断密度は、試遊結果をもとに引き続き調整する。
