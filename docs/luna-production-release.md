## 確認方法と残る制約

新しい強制チュートリアルは新規世界だけで進む。既存セーブを残して導入を確認する場合は、
プライベートウィンドウで通常版を開く。既存世界のOP再視聴はガイドの「物語を振り返る」から可能。
旧キャッシュが残る場合は、オンラインで更新取得を待ち、ゲームのタブを全て閉じてから開き直す。
