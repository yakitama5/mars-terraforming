# ルナの初回案内とOPの音（2026-10-16）

## 今回のユーザー意向

秘書の名前を仮名のミナから「ルナ」へ変更。承認済みのマットなウルフカット、眼鏡、
少しつり目、口元のほくろ、通常/喜怒哀楽/瞬きの絵は維持する。
新規プレイはルナが強制的に操作を案内し、最初の建築だけはルナの補助で即完成させる。
プレイ中の立ち絵は通常の会話より一回り小さくして、画面と操作対象を残す。
OPには音楽と、可愛くて凛々しい女性の英語ナレーションを希望。生成手段はGemini TTS等。

## 初回の流れと保存

住宅の選択・配置・費用確認 → ルナに完成を依頼 → 税収と維持費の説明 →
生命維持研究の予約 → 自由プレイと既存の6工程手引き、の5段階を追加。
手引きは引き続き約1時間の開発を案内する。短い強制操作だけで1時間の内容を達成したとは扱わない。

新規世界に段階と対象建設のIDを保存する。項目のない旧セーブは導入済みとして継続する。
最初の住宅も通常の建設費を支払い、補助はその支払済み1件を既存の完了処理へ通す。
世界の時計・他工程・研究を加速せず、追加資金や新規報酬は配らない。
次の建築と最初の研究は通常の工期を使う。

短い強制案内が完了するまではOPと同様に経過時間を消費せず、読書中の初期資金を保護する。
完了した時点から通常の時刻処理を再開する。旧世界とOP再視聴は従来どおり進行する。
各操作は候補状態の保存成功後だけ画面へ公開し、保存失敗時は元の手順から再試行できる。
正常保存の確定後に応答だけ失敗した場合も、再起動時は確定済み世代から再開する。

表示名と読み上げ名はルナへ統一。`MinaPortrait`等の識別子と画像ファイル名は既存資産との
互換性のため維持する。過去の制作記録にあるミナは当時の仮名として残す。

## 音楽と英語音声

OPに40秒のオリジナルBGMを同梱。都市・打上げ・月・探査・移住の各8秒に合わせて展開する。
制作方法・音量・再生成検証は [音楽の記録](opening-music.md) を参照。
採用した再生依存は **audioplayers 6.8.1**。`pubspec.yaml`/`pubspec.lock`へ固定する。
[公式パッケージ](https://pub.dev/packages/audioplayers/versions/6.8.1) を確認した。

再生は映像の時計に追従し、一時停止・背景移行・別画面・スキップで音も止める。
ブラウザの自動再生制限時は「音楽つきで最初から見る」を表示し、タップで再試行する。
ミュートは同じセッションのチュートリアル音声にも適用。動きを減らす設定では静止画を
手動で進めるため、自動で40秒の音声だけが先行することはない。

英語はOP5本と強制案内5本の台本を `tools/audio/luna_script.json` に準備した。
GeminiのLedaを候補に、明瞭で軽く明るい成人女性、かわいさと落ち着いた勇ましさを指定。
本人の声の模倣ではない。**現時点ではGeminiキー/接続がなく、英語音声は未生成・未同梱。**
音声なしを生成済みと偽装するファイルやOSの仮読み上げ音声は入れていない。
日本語の説明と操作は音声なしで全て進められる。

生成できる環境では `tools/generate_luna_voice.py` を実行し、続いて
`tools/mix_opening_audio.py` で音量調整・40秒ミックス・カタログの切替を行う。
キーは環境変数 `GEMINI_API_KEY` またはリポジトリ外の `--key-file` から取得し、
アプリや記録へ埋め込まない。実行時には生成サービスの利用枠が使われる。
[Gemini公式TTS資料](https://ai.google.dev/gemini-api/docs/generate-content/speech-generation?hl=en)を参照。
全クリップの実音声と声の印象、台詞と字幕の一致を確認してから公開する。
